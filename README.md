## About

Valeria is a Windows desktop clock application built around a simple idea: even the smallest elements of your desktop deserve thoughtful design.

Inspired by Apple's design philosophy and Liquid Glass aesthetics, Valeria brings together a customizable time display, refined visual effects and desktop integration.

It is designed to feel like a natural part of your desktop rather than another application sitting on top of it.

## Features

### A clock that feels like yours
Customize the appearance of your desktop clock with different visual styles, typography and themes.

### Liquid Glass-inspired design
Explore translucent materials, refined visual effects and a modern interface.

### Desktop integration
Wallpaper-aware positioning and thoughtful desktop behavior help Valeria fit into your environment.

### Personalization
Adjust the clock's appearance and available visual settings to complement your desktop setup.

## Installation

1. Open the [Releases page](https://github.com/1xpi/Valeria/releases).
2. Choose the latest available release.
3. Download the Valeria ZIP asset, not the automatically generated source-code archives.
4. Extract the archive.
5. Run `Valeria.exe`.

Keep the extracted application files together when running Valeria.
