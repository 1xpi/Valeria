# Valeria
Valeria is a modern Windows desktop clock application, inspired by the elegant and simple design philosophy of Apple.  Built around a refined Liquid Glass esthetic, Valeria brings together beautiful time displays, customizable themes, smart reminders, and thoughtful desktop integration for a seamless experience.
 Valeria

**Bring a bit more beauty to your everyday desktop.**

Valeria is a desktop clock for Windows that I'm building with one overriding objective in mind: even the little things on your desktop deserve good design.

Inspired by Apple's own approach to simplicity and the Liquid Glass look, Valeria is looking to make checking the time a bit more special.

### What I'm working on

- A good-looking clock that you can change to fit your style.
- An interface inspired by Liquid Glass.
- Various themes and visual styles.
- Reminders that will work when you need them.
- A far more natural experience on Windows.

### Why Valeria?

I've always liked apps that pay attention to the little things. The animations, the transparency, the spacing, the way everything just fits together.

That's the kind of experience I'd like to create with Valeria.

It's still very much a work in progress and there's a long way to go. This is the repository where I'll be documenting that journey.

### Development

Valeria is still in active development. Things can and will change, features may be incomplete and bugs are to be expected from time to time.

Built with:
- C#
- WPF
- .NET
